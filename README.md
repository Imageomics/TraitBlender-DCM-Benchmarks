# TraitBlender-DCM-Benchmarks — code

This repository is the **generation recipe** for the [TraitBlender-DCM-Benchmarks](https://huggingface.co/datasets/imageomics/TraitBlender-DCM-Benchmarks) dataset: phylogenetic trait simulations (BM, Pagel’s λ, regime OU), TraitBlender / MorphoWeave imaging templates, and Slurm drivers. Released trees, tip tables, meshes, and renders live on Hugging Face—not in this repo.

[Dataset](https://huggingface.co/datasets/imageomics/TraitBlender-DCM-Benchmarks) | [TraitBlender](https://github.com/Imageomics/TraitBlender) | [TraitBlender docs](https://imageomics.github.io/TraitBlender/) | [Zenodo](https://doi.org/10.5281/zenodo.14804133)

## Overview

Deep Comparative Methods need ground-truth trees, tip traits, and process parameters alongside complex observations. This pipeline simulates tip PCs under known comparative processes on a shared ultrametric balanced tree (\(T = 1\)), then renders three MorphoWeave morphospaces (mouse cranium, primate molar, squamate vertebra) with TraitBlender. The Hugging Face release is **3 scenarios × 3 morphospaces × 10 parameter levels × 1 replicate (`rep_01`)** = **90** imaged simulations (128 tips, 3 views, 5 frames → 1,920 PNGs each).

## Dataset

- **Hub:** [imageomics/TraitBlender-DCM-Benchmarks](https://huggingface.co/datasets/imageomics/TraitBlender-DCM-Benchmarks)
- **Not in git:** trees, tip CSVs, renders, filled job YAMLs, Slurm logs, MorphoWeave SSM databases

Point scripts at a local `DATA_ROOT` (HF working copy) and `SSM_ROOT` (MorphoWeave model libraries) as below.

## Repository layout

```text
.
  README.md
  configs/
    tabular/              # balanced_bm / balanced_ou / pagel_lambda_bm
    traitblender/         # one MorphoWeave template YAML per morphospace
      jobs/               # generated (gitignored); filled by make_jobs.sh
  scripts/
    sim_traits/           # simulate_traits.R + helpers.R
    imaging/              # make_jobs.sh + Blender Python driver
    slurm/                # publishable array templates
      local/              # site accounts/paths (gitignored)
  manifests/
    tabular.txt           # simulation array list
    imaging.txt           # imaging array list (regenerated by make_jobs.sh)
```

Job ids: `{tabular_id}__{template_id}__{sim}` (e.g. `balanced_bm__vertebra_3000_smooth__sig2_01__rep_01`).

**Checked in:** tabular YAMLs, morphospace templates, scripts, manifests, publishable Slurm templates.  
**Generated / local:** tip CSVs, trees, `run_meta.yaml`, `configs/traitblender/jobs/*.yaml`, renders, logs.

To add a morphospace: add `configs/traitblender/<id>.yaml` and include `<id>` in `TEMPLATES` when running `make_jobs.sh`. Do not rewrite existing tabular configs.

## Setup

```bash
export CODE_ROOT=/path/to/TraitBlender-DCM-Benchmarks   # this repo
export DATA_ROOT=/path/to/TraitBlender-DCM-Benchmarks-data   # HF working copy
# conda / modules: R with ape, phytools, geiger, yaml
```

**Seeds:** each tabular YAML sets `seed:` (source of truth). `simulate_traits.R` calls `set.seed()` once per config and writes `$DATA_ROOT/<id>/run_meta.yaml` (paths are absolute at write time; the Hub card redacts them to placeholders).

**Slurm:** do not commit personal account, partition, qos, or home paths. Pass those on the `sbatch` CLI. Keep site wrappers under `scripts/slurm/local/` (gitignored).

Requirements:

- R + `ape`, `phytools`, `geiger`, `yaml`
- Blender **5.1+** with [TraitBlender](https://doi.org/10.5281/zenodo.14804133) installed
- Cluster modules or binaries for headless GL (the checked-in imaging script shows an ARC-style example—edit for your site)

## Running simulations

```bash
cd "$CODE_ROOT"
Rscript scripts/sim_traits/simulate_traits.R \
  configs/tabular/balanced_bm.yaml "$DATA_ROOT"

mkdir -p "${CODE_ROOT}/logs"
sbatch \
  --account=YOUR_ACCOUNT \
  --partition=YOUR_PARTITION \
  --qos=YOUR_QOS \
  --output="${CODE_ROOT}/logs/%x_%A_%a.out" \
  --error="${CODE_ROOT}/logs/%x_%A_%a.err" \
  "${CODE_ROOT}/scripts/slurm/run_tabular_sims.slurm"
```

Configs use **10 parameter levels**; `n_rep: 1` matches the HF imaging release (`rep_01`). Raise `n_rep` in the YAML for denser replicate grids. Outputs under `$DATA_ROOT`:

```text
trees/balanced_128.nwk
balanced_bm/
  tabular/sig2_XX__rep_YY.csv       # tips + internal nodes
  tabular_tips/                     # tip-only (from make_jobs.sh)
  trees/sig2_XX__rep_YY.nwk
  params.csv
  run_meta.yaml
  renders/<morphospace>/<sim>/…
balanced_ou/
  tabular/alpha_XX__rep_YY.csv
  trees/alpha_XX__rep_YY.nex        # phytools SIMMAP (regimes)
  …
pagel_lambda_bm/
  tabular/lambda_XX__rep_YY.csv
  trees/lambda_XX.nwk               # λ-transformed; no __rep in filename
  …
```

Array size = non-comment lines in `manifests/tabular.txt` (default 3).

## Running imaging

One complete TraitBlender YAML per morphospace under `configs/traitblender/<id>.yaml` (orientations included). `make_jobs.sh` builds tip-only CSVs and fills `{csv}` / `{render_dir}` / `{ssm_dir}` into gitignored job files.

```bash
export CODE_ROOT=/path/to/TraitBlender-DCM-Benchmarks
export DATA_ROOT=/path/to/TraitBlender-DCM-Benchmarks-data
export SSM_ROOT=/path/to/morphoweave_ssms
# optional: export RENDER_ROOT=...   # default DATA_ROOT

bash "$CODE_ROOT/scripts/imaging/make_jobs.sh"
# -> DATA_ROOT/<scenario>/tabular_tips/
# -> configs/traitblender/jobs/*.yaml  (gitignored)
# -> manifests/imaging.txt

N=$(grep -cve '^\s*(#|$)' "$CODE_ROOT/manifests/imaging.txt")
sbatch --account=... --partition=... --qos=... --array=1-"$N" \
  --output="$CODE_ROOT/logs/%x_%A_%a.out" \
  --error="$CODE_ROOT/logs/%x_%A_%a.err" \
  "$CODE_ROOT/scripts/slurm/run_imaging.slurm"
```

Edit `scripts/slurm/run_imaging.slurm` module loads for your cluster (or wrap it from `scripts/slurm/local/`).
